
<h1>Inline Element vs Block</h1>

Inline -> Height and Width ❌
         Margin top bottom x
         margin left right is allowed to change
         padding allowed and content will shift left and right on x axis padding
         but on y axis padding, the element height will increase but the content will not 
         width depends on rendering of content
Block -> Height Width is Allowed
        will start with new line,
        will inhert parent container width
