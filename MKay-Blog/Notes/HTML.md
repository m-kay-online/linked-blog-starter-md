
<h1>Inline Element vs Block</h1>

Inline -> Height and Width ❌
         Margin top bottom x
         margin left right is allowed to change
         padding allowed and content will shift left and right on x axis padding
         but on y axis padding, the element/box height will increase but the content will not shift down.
         width depends on rendering of content

Inline is of two types :- Replaced(get from external source(like images videos) src) and Non-replaced (like span bold italic)

Block -> Height Width is Allowed
        will start with new line,
        will inhert parent container width
    



<h1>Box Model </h1>
Box Model is on which the structure of element and it content like height and width is given to the box. it is of 2 Types :- 
<h3>
1>Content box > height and width without padding and margin   <br>
2> Border Box > height and width with padding and margin</h3>


All element expect replaced inline elements like span follows box model.
